# キャラクター一括メーカー

> **このツールは、2026年11月30日（月）で公開を終了します。** ルームデータを ZIP で書き出す機能（ルームデータのエクスポート）は、ココフォリアの有料プラン（CCFOLIA PRO）の機能です。このツールはそれと同じ形式のデータを無料で作れてしまうため、運営からのご連絡を受け、公式の有料機能に配慮して取り下げることにしました。これまでに作ったデータは、そのまま使えます。

スプレッドシートの表と立ち絵の画像から、ココフォリアのキャラクター（駒）をまとめて作るツール。ステータス・パラメータ・チャットパレット・立ち絵・表情の差分まで入ったルームデータ（ZIP）を書き出し、ココフォリアで読み込むと駒が並ぶ。

**公開サイト: https://shiki365.github.io/character-batch-maker/**

手元で使う場合も、`index.html` をブラウザで開けば動く（サーバー不要・インストール不要。ZIP を作る JSZip だけ cdnjs から読むので、ネットにはつながっている必要がある）。

## できること

キャラクター作成サイト（いあきゃら・キャラエノ・ゆとシートなど）の「ココフォリア出力」は、探索者のシートを 1 枚作って 1 体ずつ貼るもので、立ち絵は入らない。このツールは KP が**シナリオの NPC を手早く、まとめて、立ち絵つきで**用意するためのもの。

- **メモ書きで打つ** — 空行で区切って 1 体。1 行目が名前、2 行目からは「名前 数値」を並べるだけ
  ```
  黒い影 ×3
  HP 20  DEX 80  装甲 2
  かぎ爪 70 1d6+1d4 / 回避 40
  メモ: 路地裏に出る
  ```
  - HP・MP・SAN と `値/最大` はステータス、能力値（STR・DEX・装甲・DB など）はパラメータ（DEX はイニシアチブにも）、そのほかは技能としてチャットパレット（`CCB<=70 【かぎ爪】` と `1d6+1d4 【かぎ爪ダメージ】`）
  - 判定の書き方は `CCB<=`（CoC 6 版）/ `CC<=`（7 版）/ `1d100<=` / 判定にしない から選ぶ
  - `×3` で 黒い影A〜C（または 1〜3）。立ち絵と差分は「黒い影」の画像を共有する
  - `メモ:` `立ち絵:` の行、URL の行、コマンドの行（そのままチャットパレットへ）
- **シナリオの NPC のデータをそのまま貼る** — 同じ欄に貼れば読める。作者ごとの書き方の違いを、シナリオごとの決まりではなく共通の形として吸収する
  - `STR12`（くっついた形）、`〈回避〉` `《》` `【】` `＜＞` `〔〕`、`成功値70` `成功率` `%`、`12(60)` `50%(25/10)`（もう一方の版の値）、`STR／DEX 60／50`（2 つ並べた形）
  - ダメージ: `ダメージ 1D8` `（ダメージ1D6）` `1d6のダメージ`、次の行のダメージ、`もしくは1D6+DB（…使用時）`。`+DB` は DB のパラメータを参照する `{DB}` にする
  - 見出し: `技能:` `ステータス` `武器:`（武器の名前とダメージを、同じ名前の技能に付ける）`呪文:` `備考`（読まない）、`【ココフォリア用チャパレ】`（そのままパレットに。同じ技能を 2 回書かない）
  - PDF のコピー: `D EX` `7 5`（空白で割れた文字・数字）、次の行にずれた数字、行をまたいだ括弧
  - 名前: `■名前(よみ)、肩書き` `【名前】168cm…` `肩書き─名前(よみ)` `▼エネミーデータ：名前` `名前*3（…）`
  - 版: 7 版の値（`(30/12)`、能力値が 5 の倍数で大きい、近接戦闘・射撃など）なら `CC<=`、ほかは `CCB<=`。シークレットダイス（`sCCB<=`）も選べる
  - 一覧で駒を選ぶと、元の文の 1 行ずつに何として読んだかが出る（読めなかった数字は橙）。直し方の案内も出す（NPC の間に空行、1 行目に名前、ラベルのすぐ後ろに数字）
  - 読み取ったラベルごとに、技能・ステータス・パラメータ・使わない を選び直せる（`警戒値` → パラメータ など）。選び直しはブラウザが覚え、次の NPC にも効く
  - 説明の文は、既定ではキャラクターメモに入れない（参加者にも見えるので、秘匿が漏れないように）
- **確定して、次の NPC へ** — 今の一覧（手直しも含む）を確定した駒として残し、入力欄を空にする。シナリオから 1 体ずつ貼っていける。確定した駒は一覧の先頭に残り、入力を変えても変わらない。手直しのあいだ（一覧が固定されている間）は入力欄を読み取り専用にして、確定するか作り直すかを選んでもらう。間違えたら「元に戻す」で入力の文章ごと戻る
- **作成サイトの駒を取り込む** — 「ココフォリア出力」でコピーしたもの（公式の Clipboard 形式 `{"kind":"character","data":{…}}`）を貼ると一覧に入る。立ち絵と差分を付けて書き出せる
- **NPC 向けの設定** — ステータスを非公開、盤面のキャラクター一覧に表示しない、をまとめて
- **素材（ZIP）** — 置き場の画像を `立ち絵/` `差分/` `そのほか/` に駒の名前で書き出す。ルームデータで入れた画像はココフォリアの「自分の画像の一覧」に入らないので、展開して画像を選ぶ画面にドロップしてもらう
- **表を貼る** — Google スプレッドシートや Excel の表を見出しごとコピーして貼る（タブ区切り。CSV も可。セルの中の改行にも対応）。1 行に 1 体
  - 見出しで読む列: 名前 / メモ / イニシアチブ / チャットパレット / 立ち絵 / 参照 URL / 色 / 駒サイズ / 盤面 / ステータスを非公開 など
  - それ以外の列: `10/12` の形か HP・MP・SAN なら**ステータス**（`10` だけなら最大値も 10）、ほかは**パラメータ**
  - `ステータス:気力` `パラメータ:HP` `差分:笑顔` のように見出しで決めることも、画面で列ごとに選び直すこともできる
- **画像の置き場** — ドラッグ＆ドロップ（何枚でも）。同じ中身の画像は 1 枚にまとめる
  - 画像の名前が駒の名前と同じなら**立ち絵**、`名前_笑顔` なら**差分「笑顔」**に自動でなる（区切りは `_` `-` `@` 空白 かっこ。いちばん長く合う名前の駒のものになる）
- **手直し** — 一覧で 1 体選んで、名前・ステータス・パラメータ・チャットパレット・メモ・立ち絵・差分・駒サイズ・盤面に出すかなどを直す。並べ替え・複製・追加・削除
- **見本** — ココフォリアの盤面の左上に出るステータスの表示と駒の、おおよその見え方
- **全体の設定** — 盤面に出すか（既定は一覧だけ）、駒サイズ、すべての駒に足す共通のチャットパレット
- 元に戻す / やり直す（最大 150 歩）、自動保存（表と設定は localStorage、画像は IndexedDB）、プロジェクトファイル（画像も入る）

## 仕組み

ZIP の形は、ココフォリアの配布している JavaScript から読み取った（**CCFOLIA 1.37.4 `main.09686af1.js`、2026-10-02**）。同じ日に本物のルームで、立ち絵と差分の画像が取り込まれることを確かめた。2026-10-30 に 1.37.6（`main.0f872b7d.js`）でも、取り込みの処理と駒の形が変わっていないことを確かめた。

```
__data.json   {"meta":{"version":"1.1.0"},
               "entities":{"characters":{"<20 文字の ID>":{
                   "name","memo","initiative","externalUrl",
                   "status":[{"label","value","max"}],      値は数
                   "params":[{"label","value"}],            どちらも文字
                   "iconUrl":"<画像ファイル名>","faces":[{"label","iconUrl":"<画像ファイル名>"}],
                   "x","y","z","angle","width","height","active","secret","invisible","hideStatus",
                   "color","commands","order"}},
                 "room":{},"items":{},"decks":{},"notes":{},"effects":{},"scenes":{},"savedatas":{},"snapshots":{}},
               "resources":{"<画像ファイル名>":{"type":"image/png"}}}
<画像>        ZIP の直下。名前は <中身の SHA-256（16 進・小文字）>.<拡張子>（png / jpeg / gif / webp）
.token        署名。わざと合わせない
```

- **画像** — 名前が中身と合わないと無視される。読み込むとココフォリアの共有の置き場に上がり、`iconUrl`（差分の中のものも）がその URL に置き換わる
- **外の URL は使えない** — 駒の `iconUrl` は、ココフォリアの保存先の URL でなければ捨てられる。なのでこのツールは画像ファイルだけを扱う
- **追加だけ** — 読み込みは ID ごとの上書き。新しい ID の駒が足されるだけで、ほかの種類は空なので何も変わらない（`room` が `{}` なら更新日時だけ）
- **持ち主** — 読み込んだ人になる（ZIP に書いても上書きされる）
- **盤面** — `active: true` の駒は盤面に出る。重ならないよう、横に並べて（8 体ごとに折り返して）置く。1 マスは 24
- **500 体まで** — 読み込みは 1 回の書き込みにまとめられるため
- **並び順** — `order` は「今の秒数＋連番」。あとから読み込んだものが一覧の後ろに並ぶ
- **`.token`** — 本来は `"0." + SHA-256(__data.json)`。合わせないと、ココフォリアが「外部ツールで作成および編集されたデータです…」と確認を出す。外部ツールのデータだと利用者が分かるように、わざとこの確認を出している
- 読み込めるのは GM（ルームマスター・サブルームマスター）。無料で使える（書き出しは Pro 限定だが、このツールは書き出しを使わない）

## 気をつけること

- ココフォリアのルームデータの形が変わると、読み込めなくなることがある
- ココフォリアの画像の上限は 5 MB。超える画像は、置き場と書き出しのときに知らせる
- 音声・BGM は扱わない（ルームデータにファイルとして入れられるのは画像だけ）
- 購入したシナリオ（CCFOLIA GAMES など）のルームデータは改変が禁止されている。このツールはルームデータを読み込んで書き換えることはせず、自分で作ったルームで使ってもらう
- 書き出したルームデータ（ZIP）を、そのまま配布・販売しないでもらう。ルームデータを人に渡す機能（ルームデータのエクスポート・公開リンク）は CCFOLIA PRO（ココフォリアの有料プラン）の機能なので、ルームを配るときは、ココフォリアに読み込んでからエクスポートしたものを配ってもらう（画面の「知っておいてほしいこと」にも書いてある）
- 置き場の画像はブラウザの中にだけある（サイトデータを消すと消える）。別の PC に移すときはプロジェクトファイルを使う
